# Vite

## 简介

当前最主流的 Web 前端构建/开发服务器。开发期追求极速冷启动与热更新，生产期追求产物质量；它的成功让它逐渐成为许多框架的"元框架"（框架基于 Vite 构建）。

## 关键事实

- **作者与团队**：尤雨溪（Evan You）创建，团队成立 VoidZero 公司推进 Rust 化工具链。
- **Vite 8（2026-03）**：以 **Rolldown** 作为唯一打包器，取代此前"开发用 esbuild + 生产用 Rollup"的双流水线；构建速度提升 10–30 倍量级。
- **Rolldown**：VoidZero 基于 OXC（Rust 写的 JS/TS 解析器）实现的打包器，兼容 Rollup/Vite 插件 API；1.0 于 2026-05 发布。
- **Vite 的取舍**：主动放弃 IE 兼容，换取更现代的产物与更简单的默认配置。
- **为什么没到"通吃"**：早期双流水线带来开发/生产偶发不一致；存量项目迁移成本、插件兼容也是阻力。
- **配套生态**：Vitest（测试）、oxlint / oxfmt（lint / format）、Vite+（统一工具链入口）。
