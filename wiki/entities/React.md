# React

## 简介

最成熟的前端框架之一，以组件化 + 单向数据流为核心；它的优势不止于"写页面"，而是带动了一整条生态：组件库、路由、状态管理、SSR、跨端渲染器。

## 关键事实

- **定位**：被视频作者视为"业界最成熟的方案"；不适合的场景主要是极简页面和不想引入框架的原生项目。
- **组件库**：Ant Design / Ant Design Pro（阿里系，中台内部系统）、MUI（Google Material 风格）；自有设计风格用 Headless UI（Tailwind 团队，无样式组件）。
- **元框架**：Next.js 提供路由、状态、SSR 等开箱能力（视频转写作"nexgs"，实为 Next.js）。
- **跨端**：桌面 Electron、浏览器扩展 WXT/Plasmo、移动 React Native，均以 React 为渲染层抽象。
- **与 TS 的关系**：TS 类型在 React 组件 props/状态上收益最大，官方类型支持完善。
