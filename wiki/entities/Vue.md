# Vue

## 简介

与 React 并列的主流前端框架，特点是模板语法直观、上手快、官方生态收敛（路由、状态、构建都有官方方案）。作者尤雨溪也是 [[Vite]] 的创建者，两者天然同源。

## 关键事实

- **组件库**：Element Plus（Vue 3 版本）。Element 2 已过时；Element3 是自媒体作者做的教学项目，不可用于生产。
- **元框架**：Nuxt 提供路由、SSR、自动导入等能力（视频转写含糊，此处按通行事实补全）。
- **小程序**：uniapp 属于 Vue 生态，Vue 团队做小程序用它摩擦最小。
- **跨端**：相比 React 的 Electron/RN 体系，Vue 的跨端重心更多在小程序与 H5。
- **版本提醒**：Vue 2 与 Vue 3 的生态（组件库、插件）不通用，选型先确认大版本。
