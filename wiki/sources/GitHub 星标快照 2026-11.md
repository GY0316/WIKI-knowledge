# GitHub 星标快照 2026-11

## 核心观点

- 这份文件不是文章，而是**一份数据快照**：GitHub 账号 `GY0316` 的公开星标仓库清单。当前基线为 2026-11-15 抓取，共 96 条；上一份 2026-11-14（95 条）保留用于对比。
- 它的价值在于“可复核”：星标数量、语言、星数、最后推送时间都是平台返回值，后续可以重抓对比，看兴趣漂移。
- 它的边界很明确：**只含公开星标**，且不含用户在网页端自建的 star 列表（Lists）分组。

## 关键内容摘要

- 获取方式：`GET https://api.github.com/users/GY0316/starred?per_page=100`，无鉴权，按页抓取后合并。
- 字段：`full_name`、`description`、`language`、`topics`、`stars`、`forks`、`archived`、`fork`、`pushed`、`url`、`homepage`。
- 结构特征：96 条中 83 条最后推送在 2026 年，说明星标以近期活跃项目为主；`language` 为空的 13 条多为纯文档/提示词类仓库。
- 版本差异：2026-11-14 → 2026-11-15 新增 1 个（`jeessy2/ddns-go`，Go 写的 DDNS 客户端），无移除。
