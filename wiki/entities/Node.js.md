# Node.js

## 简介

让 JavaScript 脱离浏览器运行的运行时，同时也是整个前端工具链的地基：TS 编译、JSX 转换、CSS 预处理、依赖安装、构建打包，全部跑在 Node 上。没有 Node，就没有当前的前端生态。

## 关键事实

- **生态定位**：不只是"服务端 JS"，更是工具链的"宿主环境"。所以"不用 Node 也能写前端"在当前工程化条件下基本不成立。
- **npm**：Node 的包管理器（Node Package Manager），负责依赖安装、版本解析、脚本执行，是人与工具链之间的"沟通层"。
- **份额**：作者称约 80%，仍是默认选择；新人精力有限就只学 Node、只用 npm。
- **竞品**：[[Bun]]（更快、四合一、2025-12 被 Anthropic 收购）、Deno（Node 作者新项目，早期生态不兼容，2026-10 团队并入 Cloudflare）。
- **版本选择**：生产用 LTS，不要追最新非 LTS 大版本。
