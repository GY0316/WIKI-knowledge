# query

## 步骤

1. 读 `wiki/index.md` 定位页面，再打开相关页面；不够时用 `grep -ril` 补查。
2. 只依据 wiki 内容回答，每个关键论断后用 `[[页面名]]` 标注依据。wiki 里没有的内容，明确写「库中暂无」，不要用自身知识冒充库内结论；若补充通用知识，单独标明「库外补充」。
3. 指出缺口：库里缺什么、建议去找什么类型的资料。
4. 登记缺口：把有价值的缺口按格式追加到 `wiki/gaps.md` 的「待学习」，已存在则不重复。
5. 若回答是对比、分析或新发现的联系，询问用户是否存为 `wiki/syntheses/` 页面。用户同意后按 `templates/synthesis.md` 创建，更新 `index.md`，追加 `log.md`：`## [YYYY-MM-DD] query | 问题`。
6. 若回答暴露了旧页面的错误或过时，列出来交用户决定，不要默默改。
