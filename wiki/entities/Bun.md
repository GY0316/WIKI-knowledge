# Bun

## 简介

用 Zig 写的 JavaScript 一体化工具链，把运行时、包管理器、打包器、测试运行器合到一个二进制里，主打"更快的 Node"。2025-12 被 Anthropic 收购，用于支撑 Claude Code 等 AI 编程工具的基础设施。

## 关键事实

- **卖点**：启动与安装速度快，`bun install` / `bun run` 一个命令覆盖多件事；对 Node 生态的 npm 包基本兼容。
- **收购**：2025-12-02 由 Anthropic 收购（原公司 Oven），保持 MIT 开源、原团队继续维护；财务条款未公开。
- **与 Node 的关系**：不是替代品的"挑战者"，更像"加速器"；Node 仍占约 80% 份额（作者口头估计）。
- **与 Deno 的区别**：Deno 追求"重新设计"（原生 TS、权限模型），代价是生态不兼容；Bun 追求"直接接住 Node 生态"。
- **风险**：生态兼容度、边缘场景行为差异仍需验证，生产替换要按项目评估。
