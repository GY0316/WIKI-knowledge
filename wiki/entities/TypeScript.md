# TypeScript

## 简介

给 JavaScript 加上静态类型系统的语言，编译期检查类型，编译后仍是普通 JS。它解决的不是"性能"或"写法"，而是**把错误从运行时提前到编码时**，同时给工具和 AI 提供可读的结构信息。

## 关键事实

- **核心例子**：`let name: string = "李积累"` 之后再写 `name = 18` 会直接报错；JS 则允许同一个变量换类型赋值。
- **采用率**：作者称正规项目约 90% 使用（口头估计），新项目默认 TS 已是行业惯例。
- **对 AI 友好的实质**：类型定义即结构化上下文。模型看到接口签名和数据结构，比读一堆无类型的实现更容易写对代码。
- **成本**：配置（tsconfig）、第三方库类型质量、历史 JS 项目迁移的渐进成本；但收益通常大于成本。
- **与运行时无关**：TS 本身不运行，靠 [[Node.js]] 或 [[Bun]] 里的编译器/转译器处理。
